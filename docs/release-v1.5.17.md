# 数据汇总工具 v1.5.17

- 新建配置从独立默认值开始，不再复制已有链接、分类和账号。
- 桌面采用蓝灰配色，改善菜单切换、滚动、保存快捷键及独立任务日志展示。
- 修复快速切换时字段可能保存到其他配置的问题，减少重复创建控件。
- 升级安全依赖，增加本机接口保护，改进发布请求、鉴权、缓存和打包边界。
- Windows 下的 Cloudflare 令牌、发布密钥和站点密码使用当前用户加密保护；原有配置会自动迁移。
- 汇总、筛选、分类计数和写入规则保持不变。

下载 Windows 安装包 `data-summary-tool-setup-v1.5.17.exe` 可直接安装；便携版请解压整个目录后运行。

升级前请先退出旧程序。安装目录和用户配置目录保持兼容；请勿删除自己的配置或服务账号文件。换电脑或 Windows 账户后，需要重新填写受保护的密钥。

公开源码及发布包只包含程序、公开依赖和示例，不含运行配置、账号凭据、实际表格/素材 ID、人员或分类案例。源码来自独立的无历史发布分支，未强推或删除旧历史。

验证：176 项 Python 测试、29 项 Node 测试、语法与隐私检查通过。Windows 程序已在本机验证构建；Release 文件由 GitHub Actions 构建并提供来源证明。

软件升级不会自动部署网站端修改或重新发布图库数据。
