# 数据汇总工具 v1.5.18

- 优化 macOS 原生渲染下的界面配色与文字对比度，消除 Aqua 按钮浅底白字与灰白外框。
- 自动适配 macOS 浅色/深色系统外观，统一输入框、表格单元格与下拉框背景及聚焦高亮。
- 完善打包图标与启动 Logo 加载机制，补充 macOS 多尺寸原生 `logo.icns` 图标。
- 优化 Windows 安装包桌面与开始菜单快捷方式图标绑定，避免中文路径下图标显示异常。
- 完善跨设备配置导入/导出功能与安全迁移验证。
- 汇总、筛选、分类计数和多工作表同步规则保持稳定兼容。

下载 Windows 安装包 `data-summary-tool-setup-v1.5.18.exe` 可直接安装；macOS 用户解压对应的 `.app.zip` 后拖入「应用程序」即可运行。
