# 配置迁移与共同维护图库

顶部“配置导入 / 导出”可以生成加密的 `.dsconfig` 文件。设置至少 10 个字符的迁移密码，另行保管；遗忘后无法恢复备份。

导出前在列表选择一个或多个配置，默认选择当前左侧配置，也可全选。只导出所选菜单及关联的 Cloudflare 站点、账号；未选菜单和归档菜单不会包含。勾选服务账号时，包含这些配置使用的共享服务账号。导入部分配置时，本机其他菜单及原账号的其他菜单授权保留。

导出包含表格配置、菜单编号、Cloudflare 账号与站点、发布密钥，以及勾选后包含的服务账号。迁移文件拥有对应账号的能力，只应交给可信的维护人员，不要放入代码仓库、公开网盘或群聊。迁移文件和密码应分开发送。

在另一台电脑导入同一文件，输入迁移密码，核对数量后确认。同编号菜单替换，其他本机菜单保留；服务账号路径重新定位，本机敏感字段重新加密。导入前自动备份到本机 `private-backup`；失败时回滚。导入的定时任务暂停，核对后再开启。

导入不会部署网站、修改线上密码或发布数据。多人维护同一站点时，保留相同站点、发布密钥和菜单编号，直接点“发布图库”。同一配置后发布的内容会替换该配置上次发布的数据；应避免两人同时发布同一配置。其他配置的数据仍独立保留。

固定访问地址是自定义域名或 `https://example-project.pages.dev`。Cloudflare 部署记录中的随机子域名用于对应某一次版本，每次更新会不同，不应作为维护者共享的固定地址。

“多账号与发布范围”提供分开的操作：

- 连接已有站点：填写原发布密钥，核验既有项目，仅保存本机配置，不生成新密钥。
- 复用已保存站点：不重新部署。迁移后首先使用此项或直接发布数据。
- 修改 / 重置访问密码：不需要原访问密码，但需要有效的 Cloudflare API Token 与原站点记录。只更新 `ACCESS_PASSWORD`，并部署原项目使其生效；留空会公开访问，需要确认。
- 恢复线上发布密钥：仅在从原电脑 / 备份找回原值后使用。只更新 `CACHE_PUBLISH_SECRET` 并验证发布接口，不改访问密码，不生成替代值。
- 更新原站点网页程序：沿用线上环境变量和 R2，不更换发布密钥。
- 创建全新站点：仅在确认域名未绑定现有站点时创建；遇到已有项目不会自动覆盖。

访问密码和发布密钥是两回事：前者给访客登录，后者允许软件修改图库数据。Cloudflare 不返回发布密钥原文；发布密钥丢失时先从其他维护电脑或加密备份找回，不能通过重新部署随意生成替代值。

本地修复依据：Cloudflare 官方 Wrangler `packages/wrangler/src/pages/secret/index.ts` 使用仅含指定变量的 PATCH 更新密钥，不回传 GET 中隐藏的旧密钥值。参考 https://github.com/cloudflare/workers-sdk/blob/main/packages/wrangler/src/pages/secret/index.ts 。
