# 数据汇总工具

当前版本：v1.5.18。Release 提供 Windows 安装包 / 便携 ZIP，以及 macOS Apple Silicon 的 `.app` ZIP。

左侧可配置菜单管理多套独立任务。目前保留贴文筛选汇总、贴文汇总、视频提取时长，并新增多工作表汇总。源码本地修改尚未打包到 Release。

## 环境

- Python 3.10+
- Google 服务账号 `credentials.json`（需对源表和目标表有编辑权限）

```bash
pip install -r requirements.txt
```

在软件顶部点击「设置」，可添加、查看、复制或移除 Google 服务账号 JSON。账号对所有模板共用，添加后会立即保存，重启后仍会显示。

## 启动

**本地软件（推荐）：** Windows 双击桌面「数据汇总工具」，或运行安装包 `data-summary-tool-setup-v1.5.18.exe`。Mac 解压 `data-summary-tool-macos-arm64-v1.5.18.zip`（Apple 芯片），把「数据汇总工具.app」拖到「应用程序」；若提示无法打开，按住 Control 点图标再选打开。重新打包 Windows：`pack.bat`。

源码启动：双击 `启动界面.bat`，或：

```bash
python desktop_app.py
```

启动后打开桌面窗口。源码版沿用已安装版的配置；测试新界面前先关闭旧软件窗口。已开启的保留模板定时任务仍按原配置执行。

## 功能

- **贴文筛选汇总**：按配置列抓取，日期过滤，阈值拆成全部 / 高亮两张结果表；默认按编号列增量更新。
- **贴文汇总**：按列表里的表格链接读取各表明细工作表，对照查找后写入整合表；来源、列、日期和目标都可在界面配置。
- **视频提取时长**：保留逐条日志表和时长统计，支持断点续跑；表头第一次写入后固定，后续按姓名顺序刷新日期数量。
- **多工作表汇总**：在同一个配置菜单中分别配置图片和视频，每类可添加多个来源链接，遍历各来源的可见子 Sheet，并排除指定名称；可读取来源表头或手动配置“汇总表头 ← 来源列”。共用目标表格，图片、视频写入不同 Sheet；各自的表头行、起始行列和展示规则独立保存。重复运行替换汇总结果，不排重；保留超链接与样式，所有来源读取成功后才开始写入该类结果。
- 每个左侧配置菜单使用独立运行状态；一个配置运行时，其他配置仍可同时启动。
- 左侧菜单可重命名、增加同模板配置；每个菜单保存独立设置。筛选、贴文和视频模板保留定时执行（需保持程序运行）。
- 旧目录汇总、字段对齐、自定义分类和指标同步不再出现在菜单；原配置在保存时归档到 `ui_archived_menus`，不再参与定时执行。

## 多工作表汇总图库

- 汇总字段可勾选“超链接”；“成品链接”等链接表头默认启用，保留原来的显示文字与点击地址。
- 已有结果丢失链接时，可在字段配置中点“修复目标表已有超链接”。只补回可确认对应关系的原链接，不改文字或其他列；重名且无法确定地址的内容跳过并报告。
- 设置中的“多账号与发布范围”可保存多个 Cloudflare Token/账号，逐个授权可发布的配置，站点与账号绑定；一个账号不能发布到另一个账号的站点。
- 新图库前端整合自用户提供的 Q Gallery 项目，位于 `summary-gallery/`。数据由软件直接读取并推送 Pages/R2，不运行 Apps Script。
- 图片、KB视频、效果视频在同一个菜单中配置；三类分别保存表格、Sheet、列映射及展示规则，共用账号和域名，形成独立数据流。
- 每类都可点击“+ 添加来源表格链接”。同一类的多个来源共用该类字段映射和排除名单；同一表格以不同 URL 或 gid 重复填写时按表格 ID 只读一次。输出 Sheet 在来源表中时，两个输出 Sheet 都自动跳过。
- 原视频配置迁入 KB视频，保留所有链接、规则和原数据通道，效果视频默认未启用，不会清空原配置。
- 在模板中配置日期、成品链接、分类、标题和可选缩略图列。默认 A 日期、B 成品链接、C 标题、D 分类；均指目标汇总 Sheet 的实际列字母。
- 图片默认延后 4 天，视频默认 7 天；例如 20 日图片从配置时区的 24 日零点开始显示。软件可修改天数和时区；发布后服务端自动按日期开放，不需要每天重新发布。
- 可发布汇总结果，也可选择“直接读取指定表格发布”：贴链接、指定 Sheet（或链接 gid）、加载表头并配置来源列，即可点击“发布图库”，无需汇总来源或目标表。直接模式只读取 Google 表格，不创建或写入汇总表。所有分片完整后再切换对应类别版本，未到展示日期的数据不会返回。
- 网页首次完整加载后保存本地列表；再次打开先在线校验版本及展示日期，没有变化就复用本地缓存，只发一次版本校验请求。数据更新、跨天或强制刷新时重新加载。
- 第 6 步可启用定时汇总与发布：默认每 3 小时，快捷 6/8/12 小时，也支持自定义分钟，需保持软件打开；本配置上一轮未结束时不会重复提交。
- 每个类别可填写不发布到图库的分类名单，按完整名称匹配，只过滤发布内容，不删除原表或汇总表数据。手动和定时发布都应用此规则。
- 单独发布会先检查接口，再读表。自定义域返回 522 等源连接错误时，仅在核验所选账号的同一个 Pages 项目后使用其备用域名；不会向猜测的站点发送密钥。部署时如自定义域未验证完成，先使用 Pages 默认地址，不把待生效域名报成可用。
- Google Drive 文件必须允许网站访问者查看。默认提取其缩略图；视频用 Drive 预览播放器，图片可打开大图。网页收藏保存在本机浏览器。
- 旧贴文图库与新汇总图库类型独立，避免覆盖旧站。账号 Token 和网站密钥保存在本机数据目录的 `cloudflare.json`，不放到网站或 Git。

## 发布图库

图库站点代码在 `promo-site/`。完整部署流程见 [`promo-site/DEPLOY.md`](promo-site/DEPLOY.md)。密钥怎么填见 [`Cloudflare发布密钥说明.md`](Cloudflare发布密钥说明.md)。

- 已有图库站点：在软件第 4 步填写发布地址和发布密钥。地址形如 `https://gallery.example.com/api/publish-cache`。
- 只更新现有网页或接口：在 `promo-site` 目录对已有 Pages 项目执行 `npx wrangler pages deploy`（项目名换成自己的）。
- 新的独立图库：软件 **设置 → 图库站点**，登录 Cloudflare，填自己的域名（例如 `gallery.example.com`），点部署。密钥自动生成并写回第 4 步。

## 审核类型

本仓库为本地 Python 脚本（无独立构建产物），按平台规范以 **源码审核** 提交。
