# 数据汇总工具

当前版本：v1.5.15。Release 提供 Windows 安装包 / 便携 ZIP，以及 macOS Apple Silicon 的 `.app` ZIP。

左侧可配置菜单管理多套独立任务，右侧按模板完成 Google 表格筛选、合并、字段映射和视频分类汇总。

## 环境

- Python 3.10+
- Google 服务账号 `credentials.json`（需对源表和目标表有编辑权限）

```bash
pip install -r requirements.txt
```

在软件顶部点击「设置」，可添加、查看、复制或移除 Google 服务账号 JSON。账号对所有模板共用，添加后会立即保存，重启后仍会显示。

## 启动

**本地软件（推荐）：** Windows 双击桌面「数据汇总工具」，或运行安装包 `data-summary-tool-setup-v1.5.15.exe`。Mac 解压 `data-summary-tool-macos-arm64-v1.5.15.zip`（Apple 芯片），把「数据汇总工具.app」拖到「应用程序」；若提示无法打开，按住 Control 点图标再选打开。重新打包 Windows：`pack.bat`。

源码启动：双击 `启动界面.bat`，或：

```bash
python app.py
```

浏览器会打开 `http://127.0.0.1:8765`。每天打开一次即可；若距上次同步已超过间隔，打开后约 12 秒会自动跑一轮。谷歌表格里的 Apps Script 定时器可以停掉。

## 功能

- **贴文筛选汇总**：按配置列抓取，日期过滤，点赞阈值拆成全部/高赞两张表；默认按 B 列帖文 id 增量更新。
- **贴文汇总**：按数据列表里的表格链接读取各表「订阅」工作表，对照贴文库后写入整合表；来源、列、日期和目标都可在界面配置，服务账号用顶部「设置」里的 JSON。
- **目录表驱动汇总 / 电话号码备份**：支持多个目标表，写入前跨全部目标表按电话号码全局排重，再把新增行均衡分配；只写有数据的列，空行跳过，分批读写。
- **字段映射 / 表头对齐**：配置“目标字段 ← 源字段”，也可按单个源链接覆盖默认映射，缺列留空。
- **视频提取时长**：保留逐条视频日志表和原时长统计，支持断点续跑；表头第一次写入后固定，后续按姓名顺序刷新日期数量。
- **自定义数据汇总**：不查询视频时长、不写日志，按日期、人员和分类统计条数；表头第一次写入后固定，后续按姓名和分类列刷新。
- 每个左侧配置菜单使用独立运行状态；一个配置运行时，其他配置仍可同时启动。
- 左侧菜单可重命名、增加同模板配置；每个菜单保存独立设置。贴文、字段对齐和视频模板支持定时执行（需保持程序运行）。

## 发布到 Cloudflare

图库站点代码在 `promo-site/`。完整部署流程（给人看、也给 AI 照着做）：[`promo-site/DEPLOY.md`](promo-site/DEPLOY.md)。密钥怎么填：[`Cloudflare发布密钥说明.md`](Cloudflare发布密钥说明.md)。

- 发到现网 `promo.zhixianglife.com`：软件第 4 步填发布地址和 `CACHE_PUBLISH_SECRET`，不必新建项目。
- 只更新现网网页/接口：

```bash
cd promo-site
npx wrangler pages deploy . --project-name=q-gallery-promo --commit-dirty=true --branch=production
```

- 独立图库：软件 **设置 → 图库站点**，登录 Cloudflare，填自己的域名，点部署。密钥自动生成并写回第 4 步。
