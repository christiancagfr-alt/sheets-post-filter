# 多工作表汇总图库

界面基于用户提供的 `E:\q-gallery-self-hosted-20260725\index.html`，保留目录、筛选、卡片与预览布局。
数据由桌面软件直接推送，不使用 Apps Script、Vercel API 或旧服务器。

Pages Advanced Mode 运行 `gallery-worker.js`（部署时作为 `_worker.js` 上传），绑定私有 R2 `GALLERY_CACHE`。
软件使用 `/api/summary-publish` 分片上传，以配置菜单和图片/视频类别区分数据流。原有单类配置迁入后沿用原数据流，避免重复。完整上传后才切换该流版本。
`/api/gallery` 仅返回按配置时区达到展示日期的素材；不开放原始 R2 分片或 CDN 路由。

软件中：设置 → Cloudflare 账号管理，添加账号并授权可发布的菜单，部署“多工作表图库”。
一个菜单包含“图片 / KB视频 / 效果视频”三套独立配置，共用账号与域名。原有视频配置迁入 KB视频，保留原数据流 ID 和全部链接，效果视频默认禁用。
每套可选择“发布汇总结果”或“直接读取指定表格发布”：汇总模式可添加多个来源并设置目标 Sheet；直接模式只需现有表格、Sheet（或链接中的 gid）、表头行和数据起始行，可加载表头查看列字母，按来源列配置日期、链接、分类、标题、制作人、缩略图，无需配置汇总来源/目标或创建新表。两种模式发布时都只运行已启用的类别。
“开始汇总”只处理选择汇总模式的类别；“发布图库”同时支持两种模式。直接发布全程只读 Google Sheets，KB视频和效果视频在网站中是两个独立目录。
每个类别可配置“不发布到图库的分类”，一行一个完整名称，留空则不排除。只过滤发布素材，来源及汇总表保留全部行；“未分类”对应空分类。发布时记录排除数量，若有效素材全部被主动排除，会将该类别的线上列表置空，其他类别保留。
第 6 步是本配置的独立定时器：默认 180 分钟，快捷 3/6/8/12 小时，也可输入自定义整数分钟。勾选“启用”并保存应用，可选择定时汇总和/或发布；同时勾选时，汇总模式复用刚汇总的行直接发布，不再重复读取目标 Sheet，直接发布模式跳过汇总。支持立即执行一轮。
需保持软件打开，最小化可继续，关闭后停止；重开保留剩余时间，若已经到期则补跑一次。到点时本配置仍在运行/排队，则一分钟后再检查，不重复提交；各菜单保留各自定时。修改分类排除名单后，下一次定时发布使用新规则。
来源可选择“排除列出的子 Sheet”或“只读取列出的子 Sheet”；名单按完整名称匹配，一行一个。只读取模式至少需要一个名称，未匹配到任何子表时不会清空目标。隐藏及输出 Sheet 在两种模式下都跳过。旧配置默认保持排除模式。
发布后网页仅从 Cloudflare 的私有 R2 读取展示数据，不调用 Google Sheets；图片与视频文件仍从原 Google Drive 链接加载。源表变动后由桌面软件重新汇总、发布，访客刷新不会触发表格同步。
默认图片延后 4 天、视频延后 7 天，按日期当天 00:00 起算。例如 20 日图片在 24 日开始显示。

Google Drive 文件需要允许网站访问者查看；软件能读表不代表访客能访问私有媒体。
Google Drive 视频在预览窗口内播放；图片打开大图。可选缩略图列，否则使用 Drive 文件缩略图。
制作人默认读取汇总后的 G 列，可在“网页展示规则”中修改或留空；源表 G 列也需要包含在汇总字段里。
网页固定使用网格布局，制作人筛选来自已到展示日期的素材。
网页收藏是本浏览器的本地收藏；源表刷新仍由桌面软件执行。
网页采用紧凑的浅蓝灰配色，搜索与收藏同行，首页直接展示网格。首批渲染 90 张卡片，滚动接近底部再追加，筛选仍覆盖全部已加载素材。
Drive 下载按钮会把旧 `/view` 链接转换为原文件下载地址，并保留 resource key，由 Google 的附件响应触发浏览器下载；不会经 Cloudflare 中转或复制媒体。其他允许跨域读取的文件来源使用浏览器 Blob 下载，不支持时明确提示并提供“打开原文件”。

配额优化：静态网页不触发 Worker；首次素材按 500 条分片读取，先显示首批，再继续加载。完整、同版本的结果保存到本浏览器 IndexedDB；重新打开先在线验证登录和 cacheKey（构建版本+展示日期），一致时只做一次版本校验并读取本地列表，不请求 list 分页。新发布、跨天、强制刷新、登录失效会弃用旧缓存；离线未校验时不展示旧副本。数据库禁用/空间不足则正常回退为线上读取。退出登录清理本地列表，收藏设置保持独立。
每次请求最多读取一个数据分片，时区按请求计算一次，避免逐条创建日期格式器触发 1102。
分片按内容哈希存放在私有 `summary/chunks/<stream>/`；中断可续传，未变分片复用，完整校验后再切换版本。
相同素材和展示规则再次发布时，只检查当前版本，不重复上传；旧接口仍兼容原构建分片。
每个可见网页每五分钟检查一次版本，后台标签页暂停检查，不再轮询空统计/刷新状态。
R2 清单每次通过 LIST 确认 ETag，复用相同版本；不可变分片仅在当前 Worker 实例内缓存，最多八片/四 MB。
缓存不代替访问密码和展示日期检查，也不公开未到期素材。不设置访客上限或自动升级付费计划。

这套模板不能覆盖现有贴文图库。旧域名若记录为贴文图库，请选择独立域名，保留原项目、桶和密钥。

全站不收录：HTML 带 robots noindex；静态响应通过 Pages `_headers`，接口响应通过 Worker 均设置 `X-Robots-Tag: noindex`。robots.txt 仅屏蔽接口/私有路径，页面保持可抓取以便搜索引擎识别 noindex；已经收录的地址需要搜索引擎重新抓取后移除。
